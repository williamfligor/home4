# Solarized

Adds Solarized Dark and Solarized Light to Settings → Appearance, in Ethan Schoonover's palette: base03 to base3 for surfaces and text, blue for the accent.

Pick either theme on any host running the plugin. Colors are fixed values, nothing is read or sent, and the plugin has no settings, no daemon code, and no network access. Themes need a Paseo client that supports plugin themes (0.16 or later); on an older client the plugin reports `client.addTheme is not a function`.
